Why Learn Formal Verification?

For centuries, mathematical proofs were verified by peer review—a slow and sometimes error-prone human process. Lean 4 changes this. As an interactive theorem prover, it lets you write proofs in collaboration with a computer compiler that type-checks your logic line-by-line, showing you the exact logical state of your theorem in real time.

In this course, you will learn how to turn abstract mathematical statements in algebra, number theory, and analysis into formal code that is mathematically guaranteed to be 100% correct.

Week 0: IDE & Local Environment Setup

Conquering the installation process and testing your system
Installation Guide for Non-Programmers

For mathematical students who have never opened a terminal, installing code tools can feel intimidating. Follow this step-by-step pipeline to get up and running smoothly.

1
Install VS Code

Download and install **Visual Studio Code** (VS Code). This is the text editor where we will write all of our mathematical proofs. It has a beautiful, real-time proof-checking panel.

2
Install Lean 4 and Elan

Lean is managed by a tool manager called `elan` (similar to standard system package managers). Run the automated installation script:

Windows (PowerShell):

curl -sSfL https://raw.githubusercontent.com/leanprover/elan/master/elan-init.sh | sh

Mac / Linux (Terminal):

curl https://raw.githubusercontent.com/leanprover/elan/master/elan-init.sh -sSf | sh

Select the default installation options when prompted, then restart your terminal.

3
Install VS Code Extension

Open VS Code, click on the "Extensions" tab on the left sidebar (looks like four blocks), search for **Lean 4**, and click **Install**. This connects the editor to your compiler.

4
Verification Test

To verify that everything is installed correctly, open a terminal window and run:

lean --version

If it outputs a string like leanprover/lean4:v4.x.x, your installation is successful!

Week 1: Introduction to Formal Systems

Peano Arithmetic, induction, and your first theorem proof
What is a Formal System?

A formal system is a language of symbols, rules for combining them into statements (axioms), and rules for deducing new statements (theorems). In Lean, the fundamental formal system is **Calculus of Inductive Constructions**.

For example, how do we define the Natural Numbers ($\mathbb{N} = \{0, 1, 2, 3, \dots\}$)? We define them as an **Inductive Type**:

inductive Nat where
  | zero : Nat
  | succ : Nat → Nat

This simple definition says: 1. `zero` is a natural number ($0$). 2. If `n` is a natural number, then `succ n` (the successor of `n`, or $n+1$) is also a natural number. All arithmetic and equations are built recursively on top of this Peano definition!

Interactive Tactic Cheat Sheet

Quick reference cards for core mathematical proof steps
rfl

Reflexivity. Used to prove equalities where both sides are identical or compute to the same value (e.g., x = x or 2 + 2 = 4).

rw [rule]

Rewrite. Substitutes a term in your target goal using a known mathematical equality or established theorem.

intro h

Introduction. Moves the premise of an implication or a quantifier (e.g. "Assume P") into your active hypotheses list with the name h.

apply theorem

Backward Reasoning. Matches your target goal with the conclusion of a theorem, reducing your goal to proving the theorem's premises.

induction n

Mathematical Induction. Splits your goal into a base case (e.g. zero) and an inductive step (e.g. succ n) with an inductive hypothesis.

ring

Ring Solver. Automatically proves algebraic equalities in commutative rings (like addition and multiplication of reals, ints, or rationals).
